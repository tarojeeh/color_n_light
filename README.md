# Color and Light · Học tiếng Việt

Bộ slide học cuốn Color and Light (James Gurney), dùng cá nhân.

Đưa lên GitHub Pages:
1. Tạo repo mới (nên để Private nếu tài khoản có GitHub Pro).
2. Upload toàn bộ file và thư mục img trong gói này vào thư mục gốc của repo.
3. Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
4. Đợi 1-2 phút, mở link dạng https://<tên>.github.io/<repo>/

Thêm vào màn hình chính:
- iPhone/iPad: mở bằng Safari > nút Chia sẻ > Thêm vào MH chính.
- Android: mở bằng Chrome > menu ⋮ > Thêm vào màn hình chính.

Học offline: ở trang chủ app, bấm "Tải về để học offline" khi có mạng.
